SwiftTree is a drop-in SwiftUI component that brings an IDE-style file navigator to any macOS app. It colors every entry by its git status, shows devicon file-type glyphs, and stays in sync with disk and git changes in real time — all without any dependencies outside Apple frameworks.

## What SwiftTree does

<CardGroup cols={2}>
  <Card title="Git status colors" icon="code-branch">
    Every file and folder is colored by its git status — modified, untracked, staged, deleted, or ignored — updated live as you work.
  </Card>
  <Card title="FSEvents watching" icon="eye">
    The tree watches the filesystem with FSEvents and re-reads changed directories automatically. Share one watcher across your whole app.
  </Card>
  <Card title="DevIcon glyphs" icon="file-code">
    File rows show devicon font glyphs for hundreds of languages and tools, or fall back to an SF Symbol when no icon is mapped.
  </Card>
  <Card title="Nested repositories" icon="layer-group">
    Submodules and nested repos are discovered automatically. Each repo gets its own git-dir watch and independent status refresh.
  </Card>
  <Card title="Inline editing hooks" icon="pencil">
    Trigger rename or create flows with `tree.inlineEdit`. The tree positions your own SwiftUI field inside the row — you handle the filesystem work.
  </Card>
  <Card title="Headless status API" icon="terminal">
    Use `register` and `snapshot` to consume git status without the view — useful for badge counts, CI integrations, or custom UIs.
  </Card>
</CardGroup>

## Quick look

```swift Sidebar.swift
import SwiftTree
import SwiftUI

struct Sidebar: View {
  @State private var tree = FileTree(
    root: URL(fileURLWithPath: "/path/to/project"),
    onError: { error in print("swift-tree:", error) }
  )

  var body: some View {
    FileTreeView(tree: tree) { item in
      if !item.isDirectory { open(item.url) }
    } rightClickMenu: { item in
      Button("Reveal in Finder") {
        NSWorkspace.shared.activateFileViewerSelecting([item.url])
      }
    }
  }

  func open(_ url: URL) { /* … */ }
}
```

<Steps>
  <Step title="Add the package">
    Add SwiftTree to your `Package.swift` dependencies and to your target.
  </Step>
  <Step title="Fetch the devicon font">
    Run `make fonts` to download the devicon font into the package resources before building.
  </Step>
  <Step title="Create a FileTree">
    Initialise `FileTree` with a root URL and an optional error handler. Store it with `@State`.
  </Step>
  <Step title="Embed FileTreeView">
    Drop `FileTreeView` into your SwiftUI hierarchy — sidebar, sheet, or any container.
  </Step>
</Steps>

<Note>
SwiftTree targets **macOS 14+** and has **no dependencies outside Apple frameworks**. It uses the `git` CLI (2.30+) found on `PATH` for status information.
</Note>
