By the end of this guide you will have a working file tree sidebar that colors every row by its git status, shows devicon file-type glyphs, and updates itself whenever a file changes on disk — all wired into a single SwiftUI view with fewer than 30 lines of code.

## Steps

<Steps>
  <Step title="Install SwiftTree">
    Follow the [Installation](/installation) guide to add the package dependency and run `make fonts`. Come back here once `swift build` succeeds.
  </Step>
  <Step title="Create a FileTree">
    `FileTree` is the `@Observable` model that owns the directory listing, git status engine, and FSEvents watcher. Create it with `@State` so SwiftUI owns its lifetime and the view automatically re-renders when the tree changes.

    ```swift Sidebar.swift
    import SwiftTree
    import SwiftUI

    struct Sidebar: View {
      @State private var tree = FileTree(
        root: URL(fileURLWithPath: "/path/to/project"),
        onError: { print("swift-tree:", $0) }
      )
      // …
    }
    ```

    - **`root`** — the folder to display; the tree starts with it expanded.
    - **`onError`** — a `@MainActor` closure called for non-fatal errors (git unavailable, a git command failing, or the devicon font missing). The tree continues working after every one of these.
    - **`options`** — an optional `FileTreeOptions` value (defaults to the IDE-style preset). See the [Customization](/guides/customization) guide.
    - **`watcher`** — an optional `FileWatching` instance. Omit it and the tree creates its own `FSEventsWatcher`.
  </Step>
  <Step title="Embed FileTreeView">
    `FileTreeView` renders the model as a scrollable list of compact rows. Pass the tree, an `onLeftClick` callback that receives a `TreeItemInfo`, and a `rightClickMenu` view builder for the context menu:

    ```swift Sidebar.swift
    var body: some View {
      FileTreeView(tree: tree) { item in
        // Left click: files select, folders also toggle open.
        if !item.isDirectory { open(item.url) }
      } rightClickMenu: { item in
        Button("Reveal in Finder") {
          NSWorkspace.shared.activateFileViewerSelecting([item.url])
        }
        Button("Copy Relative Path") {
          NSPasteboard.general.clearContents()
          NSPasteboard.general.setString(item.relativePath, forType: .string)
        }
      }
    }

    func open(_ url: URL) { /* open the file in an editor */ }
    ```

    Each callback receives a `TreeItemInfo` with:

    | Property | Type | Description |
    |----------|------|-------------|
    | `url` | `URL` | Absolute URL of the clicked item |
    | `relativePath` | `String` | Path relative to the tree root |
    | `isDirectory` | `Bool` | Whether the item is a folder |
    | `isSymlink` | `Bool` | Whether the item is a symbolic link |
    | `repoRoot` | `URL?` | The deepest git repo containing this item |
    | `gitStatus` | `GitStatus?` | Current git status, or `nil` when git is off |
  </Step>
  <Step title="Handle errors">
    The `onError` closure you passed to `FileTree` receives a `FileTreeError`. There are three cases:

    | Error | When it fires | Effect on the tree |
    |-------|--------------|-------------------|
    | `.gitUnavailable` | No usable `git` found on `PATH` | Fires once; tree shows no status colors or branch labels |
    | `.gitFailed(repo:message:)` | A git command failed for one repo | Fires once per repo until it recovers; other repos are unaffected |
    | `.devIconsUnavailable` | `useDevIcons` is on but the font is missing | Fires once; file rows show the generic `doc` SF Symbol |

    A minimal error handler that shows an alert:

    ```swift Sidebar.swift
    @State private var lastError: String?

    @State private var tree = FileTree(
      root: URL(fileURLWithPath: "/path/to/project"),
      onError: { [self] error in
        switch error {
        case .gitUnavailable:
          lastError = "git not found on PATH — install Xcode Command Line Tools."
        case .gitFailed(let repo, let message):
          lastError = "git failed in \(repo.lastPathComponent): \(message)"
        case .devIconsUnavailable:
          lastError = "Devicon font missing — run make fonts."
        }
      }
    )
    ```
  </Step>
</Steps>

## Complete Example

Here is the full `Sidebar` struct, ready to drop into a `NavigationSplitView` or any SwiftUI container:

```swift Sidebar.swift
import SwiftTree
import SwiftUI

struct Sidebar: View {
  @State private var tree = FileTree(
    root: URL(fileURLWithPath: "/path/to/project"),
    onError: { error in print("swift-tree:", error) }
  )

  var body: some View {
    FileTreeView(tree: tree) { item in
      // Left click: files select, folders also toggle open.
      if !item.isDirectory { open(item.url) }
    } rightClickMenu: { item in
      Button("Reveal in Finder") {
        NSWorkspace.shared.activateFileViewerSelecting([item.url])
      }
      Button("Copy Relative Path") {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(item.relativePath, forType: .string)
      }
    }
  }

  func open(_ url: URL) { /* open the file in an editor */ }
}
```

<Tip>
  `FileTreeOptions` lets you configure git detection, devicon glyphs, light/dark theme, per-status colors, font size and family, indent guides, branch name labels, and more — all in one place before you create the tree. See the [Customization](/guides/customization) guide for every option.
</Tip>

<Note>
  `FileTree` is `@Observable`, so any change to its properties — a new git status arriving, an FSEvents batch landing, `showHiddenFiles` toggled — automatically invalidates only the SwiftUI views that read those properties. Store the tree with `@State` in the view that owns it so SwiftUI manages the object's lifetime correctly. Do not use `@StateObject`; that is for `ObservableObject`, which `FileTree` does not conform to.
</Note>
